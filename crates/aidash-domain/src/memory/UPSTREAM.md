This is a semantic translation rather than Python API compatibility. The Aidash
authority, source revision, budget and delivery contracts take precedence over
upstream fallback behavior. Unsupported citations, unavailable providers and
oversized provenance envelopes fail explicitly. JSON is only typed transport
and Registry configuration; a bank has no whole-object overwrite.

Semantic/causal construction and semantic consolidation have separate pure and
native verification entries. Managed backup/restore acceptance and deployment
acceptance remain separate gates. This matrix does not claim those gates are
complete. Real PostgreSQL, UI and two-node results are recorded in the
[Issue #125 verification ledger](../../../../docs/memory-verification.md); pure modules do not establish deployment acceptance.
