## Implemented contracts

Home owns the Workspace, Task, semantic index and source authority. Required retrieval binds the exact Home index and embedding descriptor, with a separately approved optional compactor. The receiver persists a provenance receipt before inference; it never substitutes its own memory or advertises remote `memory_write`.

Foreign generation prepares one immutable receiver Agent for the Home Task, survives approval/retry/restart and activates only through the final exact grant/admission. Generated executors and generated Home ancestors each reserve their own shared-token and separate call allowances before provider HTTP. Durable dispatch records, operation fences and settlement outboxes preserve unknown charges and make completed settlement idempotent. Only proven pre-dispatch abandonment refunds a reservation.

Semantic operations retain attempts, retry deadlines, input bindings and source dependencies. Transient failure uses the initial attempt plus five retries (2/4/8/16/32 seconds); exhaustion pauses for an audited explicit retry. Changed consumed sources invalidate the Run. Replacement work uses an explicit Follow-up Task without importing invalid context.

Current readers must satisfy authority at every dependency node, and the producer's original authority must remain valid. Leaf dependency RPCs and a bounded visited-set traversal avoid recursive cross-node callbacks. Denied reads hide both nodes' journals, output resources, graph/state/event/stream projections and semantic re-ingestion. Operator content APIs also withhold these subject-bound workspaces; minimal management metadata still permits cancellation. Buffered SSE delivery and UI refreshes recheck visibility.

The dashboard provides en-US/ja-JP assignment configuration, foreign generation approval/preparation, semantic outcomes and pause reasons, provenance, generation allowances, retry/cancel and explicit Follow-up controls.

## Cluster evidence

The remote-memory profile provisions two HTTP Nodes and their workers, separate PostgreSQL databases, NATS, persistent Qdrant and deterministic embedding/model fixtures. No production lease timestamp, retry counter, fence, binding or budget is changed by this driver. The credential scenario uses only synthetic keys in the disposable Home deployment and verifies revocation, absence and same-reference rotation without recording bearer values in provider evidence. The ordinary case kills the worker after a receipt reaches inference; recovery must reuse the receipt without another embedding. The generated case kills Home after embedding dispatch, holds the Home link unavailable, restarts both servers and the receiver worker, and verifies that the unknown attempt remains charged before a new attempt and inference complete. It then deletes a consumed source and proves content denial while minimal management remains readable. A completed Run correctly rejects cancellation; the local integration suite separately verifies cancellation of an active hidden Run.

A forced Kubernetes Pod deletion alone was insufficient evidence of process death: the old process could still finish before the runtime stopped it. The driver now freezes the owned container process, scales its deployment to zero, sends SIGKILL through that disposable cluster node's runtime PID, and observes process exit before releasing the provider response. Evidence records the Pod UID, container ID, runtime PID and signal.

## Reproduction and limits

Run `scripts/test-rust.sh`, `npm run build --prefix web`, `npm run test:ui --prefix web`, and both remote-memory cluster profiles from this branch. The test script supplies synthetic service secrets; do not use production credentials for the fixtures. The cluster script uses private kubeconfigs and removes only its own disposable cluster.

The whole Rust regression exposed a provisional remote-read cache result that could omit queued authority edges later in the same response. Leaf evaluations now bypass final-decision caches; the existing revoked-discovery regression verifies the repair. The regression suite also preserves the existing reader path for a legacy remote Run with an exact local execution authorization, while scoped admissions always retain their foreign authority checks. Generation reconciliation acquires the existing atomic visibility lease before foreign lifecycle or settlement scans, preserving explicit transaction-pending behavior during distributed recovery. Local process tests use a task-specific Cargo target and build directory to keep another checkout from replacing their child executable.

The deterministic fixtures prove plumbing, authority, accounting and recovery. They do not benchmark semantic quality, test arbitrary mixed-version deployments, or establish production deployment state. Hosted CI is a separate result attached to the final PR. This ledger does not close unrelated release requirements or publish changes to Notion.
