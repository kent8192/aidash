# Pin external model versions and historical branch rules

A Decider selects a concrete external model version, rejects mutable aliases, and validates the response's model identity because an immutable Registry definition alone cannot freeze an alias's meaning. Read-only branch replay uses the recorded evaluator version and exact validated probability/threshold values, while recovery and action application also require current authority and restrictions. This accepts explicit reapproval for provider upgrades and retention of historical evaluator semantics in exchange for an audit that does not silently change when the service or operator is upgraded.
