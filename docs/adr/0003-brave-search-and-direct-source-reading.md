# Use Brave for discovery and Aidash for source reading

Select Brave Web Search as the first search integration, with an Aidash-controlled reader for public HTML, plain text and text-based PDFs, because documented language, geographic and freshness controls fit the intended Japanese/English research while direct retrieval keeps source-access and evidence handling explicit. Unlike an integrated provider-generated answer or extraction pipeline, Aidash's existing model examines retrieved evidence and composes the answer, accepting responsibility for bounded extraction and network isolation. Enable search only after the actual provider plan supports the accepted storage, no-training, retention and budget requirements; this decision does not establish an eligible subscription, verify its price, or permit automatic fallback to another provider.

The [provider comparison](../design/2026-09-25-web-search-providers.md) records alternatives and the remaining evidence. Tavily and Exa's inspected standard material did not establish all accepted data conditions; no candidate's relevance was measured in this interview.
