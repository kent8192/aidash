# Keep decision dispatch on the Execution node

The Execution node builds the permitted decision state and dispatches its exact pinned Decider, while Home admits that identity, configuration, and disclosure scope before remote work. Each allowance owner reserves in its own transaction, and provider I/O waits for every durable receipt and the dispatch record; credentials and canonical evidence remain on Execution. This preserves the existing compaction placement and avoids introducing Home or third-node fallback, while requiring explicit remote approval rather than treating a local Binding as permission to disclose Home data.
