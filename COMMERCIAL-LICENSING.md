# Commercial licensing

Aidash does not offer commercial licenses.

Enterprise production use is available only through Cloud and Dedicated, which
Aidash operates on infrastructure Aidash controls. A Dedicated customer receives
a service, not a software license, so that use needs no Enterprise license. The
Enterprise source stays public under BUSL-1.1 with `Additional Use Grant: None`;
see [enterprise/LICENSE](enterprise/LICENSE).

We do not sell a license that lets anyone else run Enterprise in production.
That covers self-hosted Enterprise, a hosted Enterprise service, and a service
built from Enterprise.

For any other licensing question, contact <licensing@aidash.run> or open a
[licensing inquiry](https://github.com/kent8192/aidash/issues/new?template=licensing.yml).
The address forwards to the Licensor without publishing a personal address.

Do not post personal details, credentials, contract text or private agreements
in a public issue. See [docs/licensing.md](docs/licensing.md) for the component
rule and the earlier notices.
