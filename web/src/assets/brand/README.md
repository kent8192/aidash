# Aidash brand assets

These original assets come from the user-provided `aidash-logo-kit.zip`
(September 24, 2026), using its primary **Mesh + Accent** design.
The SVGs and favicon are copied unchanged from the kit.

- `aidash-logo.svg`: transparent wordmark for the light login screen.
- `aidash-logo-on-dark.svg`: transparent wordmark for the workspace header.
- `aidash-app-icon.svg`: supplied application icon for the navigation rail.
- `favicon.ico`: supplied browser icon from the kit's `icons/` directory.

Preserve the original proportions and colors. The wordmark lettering is already
outlined in the source SVG; do not recreate it with a font or CSS.
